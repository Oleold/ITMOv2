# Proposal

## Why

Пользователь ожидает, что клавиша Escape очищает текущий ввод или отменяет фильтрацию без необходимости тянуться к кнопке «Сброс». Это ускоряет работу с поиском и снижает трение при исправлении промахов ввода.

## What Changes

- Добавить поведение очистки поля поиска по нажатию клавиши Escape при фокусе на поле.
- На Escape вызывать существующую логику сброса фильтров и перезапроса данных (`resetFilters`).
- Ничего не менять в серверной части, кнопке «Сброс» и действующей валидации.

## Capabilities

### New Capabilities
- `ui/search-clear-on-esc`: Поведение UI, при котором нажатие Esc в поле поиска очищает ввод и выполняет сброс фильтров.

### Modified Capabilities
- `ui/search-and-filter`: Добавление сценария очистки по Esc к существующему поведению поиска и фильтрации на клиенте.

## Impact

- UI: изменения ограничиваются клиентской страницей поиска (frontend, index.html).
- API/Server: без изменений.
- Совместимость: без ломающих изменений; поведение Esc добавляется как дополнительный, обратимо совместимый путь сброса.
