# Unit-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| Не более трёх рисков | Функция форматирования отчёта ограничивает список | 5 рисков | Усечено до 3 | Тест проверяет длину |
| Обязательные поля риска | Валидация структуры риска | Риск без ссылки на строку | Ошибка валидации | Тест падает без ссылки |
| Обязательное поле diff | Валидация входного payload на уровне API | {} | 4xx с сообщением об отсутствии diff; без KeyError | Юнит‑тест ручки через TestClient; основание: TRAINING_PR.diff app/api.py:35–38 обращение payload["diff"] |
| Пустой diff | API отклоняет пустую строку | {"diff": ""} | 4xx и сообщение "diff is empty"; LLM не вызывается | Given API сервер и мок LLM; When POST /api/reviews с пустым diff; Then статус 4xx, тело с сообщением, LLM.generate не вызван |
| Ограничение размера diff | ReviewService ограничивает длину prompt для LLM | строка длиной 10000 символов | Усечено до 8000 символов | Given мок LLM; When review(diff) с 10k символов; Then LLM.generate вызван с prompt длиной ≤ 8000 |
| Ошибка парсинга ответа LLM | Обработка невалидного JSON, если выбран JSON‑протокол | LLM.generate -> "not json" при ожидаемом JSON | Понятная ошибка валидации формата без падения стэктрейсом | Юнит‑тест сервиса: перехват исключения и сообщение |
| Формат ответа сервиса | Схема ответа `review()` | любой валидный diff | dict содержит ключ `comment` (str), без лишних полей | Тест схемы ответа; основание: TRAINING_PR.diff app/review_service.py:19–22 возвращает {"comment": answer} |
| Тип поля diff | Валидация типа значения | {"diff": 123} | 4xx и сообщение о неверном типе; LLM не вызывается | Юнит‑тест ручки; проверка, что мок LLM.generate не вызван |
| Лишние поля в payload | Валидация формата входа | {"diff": "ok", "extra": 1} | 2xx; лишние поля игнорируются, сервис работает предсказуемо | Юнит‑тест: проверка отсутствия побочных эффектов; основание: в diff нет обработки посторонних полей (см. README) |
| Минимальная длина diff | Отсечение бессмысленного ввода | {"diff": "a"} | 4xx и сообщение "diff too short (min 5)"; LLM не вызывается | Юнит‑тест: проверка статуса и отсутствия вызова LLM |
| Инвариант: LLM не вызывается при ошибке валидации | Защита от лишних внешних вызовов | любой невалидный payload | 4xx; вызов LLM отсутствует | Юнит‑тест: счётчик вызовов LLM.generate = 0 |
