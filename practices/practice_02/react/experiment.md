# ReAct

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Цель: последовательно улучшить `practices/practice_01/tests_unit.md` действиями наблюдения и небольшими правками
- Доступные входы: `TRAINING_PR.diff`, `tests_unit.md`, `practice_01/README.md`
- Разрешённые действия: Read (просмотр файлов), Grep (поиск по содержимому), Edit (минимальные правки таблицы и подтверждений), Make (запуск `make step2`)
- Запрещённые действия: выполнение кода приложения, изменение бизнес-логики за пределами артефактов Практики, удаление ранее согласованных строк
- Максимальное число шагов: 4
- Условие остановки и вопроса человеку: остановиться, если дополнительные правки приведут к дублированию проверок или конфликту с TRAINING_PR.diff; спросить подтверждение на любые изменения статусов/политик

## Запрос

Выполнить ReAct-проход для финальной шлифовки `tests_unit.md`: проверить через Grep/Read совпадение формулировок подтверждений с источниками, найти возможные дубли или расплывчатые места, предложить ровно 1–2 минимальные правки без изменения смысла, затем запустить `make step2`.

## Наблюдаемые действия и результаты

| Шаг | Действие | Наблюдение | Решение продолжить или остановиться |
|---|---|---|---|
| 1 | Read TRAINING_PR.diff | В app/api.py прямой доступ к payload["diff"]; в review_service возвращается {"comment": answer} | Продолжить: согласуем формулировки подтверждений |
| 2 | Read tests_unit.md | Подтверждения уже содержат ссылки на строки; часть формулировок подтверждений разнородна | Предложить единый стиль: начинать подтверждения с «Given/When/Then» или «Основание: ...» |
| 3 | Edit tests_unit.md | Привёл три подтверждения к единому виду: добавил «Основание: ...» и унифицировал G/W/T для двух строк | Продолжить: проверка артефактов |
| 4 | Make step2 | Practice 2 artifacts: OK | Остановиться |
